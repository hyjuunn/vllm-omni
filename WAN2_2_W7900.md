# Wan2.2 A14B on 8x W7900

This branch is based on vLLM-Omni `7b83794` and records the setup tested on
eight PCIe-connected Radeon PRO W7900 GPUs.

Tested stack:

- ROCm 7.14, PyTorch 2.11.0
- HIP 714
- hipBLASLt `100401-cd957402`
- rocBLAS `5.5.0.cd957402`
- 241 W per GPU, `NCCL_P2P_DISABLE` unset

## Compatibility patch

PyTorch 2.11 does not contain `pytorch/pytorch@fba88a5`. On gfx1100 it can
dispatch Wan's BF16 D384 VAE attention to an incorrect AOTriton path, producing
black or partially black output. Enable the branch's Wan VAE guard with:

```bash
export VLLM_OMNI_WAN_VAE_ATTN_MATH=1
```

The guard affects `WanAttentionBlock` only. DiT attention keeps the default
PyTorch SDPA route.

## TunableOp databases

T2V and I2V use separate databases. Prepare the rank files for each workload:

```bash
bash artifacts/tunableop/w7900/prepare_tunableop_db.sh t2v /opt/wan-tunableop/t2v
bash artifacts/tunableop/w7900/prepare_tunableop_db.sh i2v /opt/wan-tunableop/i2v
```

Then set:

```bash
export PYTORCH_TUNABLEOP_ENABLED=1
export PYTORCH_TUNABLEOP_TUNING=0
export PYTORCH_TUNABLEOP_RECORD_UNTUNED=0
export PYTORCH_TUNABLEOP_VERBOSE=0
export PYTORCH_TUNABLEOP_FILENAME=/opt/wan-tunableop/t2v/tunableop-results.csv
```

Use the `i2v` directory for I2V. PyTorch adds the device number to the base
filename, so the script creates `tunableop-results0.csv` through
`tunableop-results7.csv`.

## Configuration

Both models use TP2xU4:

```text
--tensor-parallel-size 2
--ulysses-degree 4
--cfg-parallel-size 1
--ring-degree 1
--pipeline-parallel-size 1
--vae-patch-parallel-size 1
```

T2V was measured at 1280x720, 33 frames, 20 steps, seed 42. I2V was measured
at 832x480, 41 frames, 40 steps, seed 42. Both used VAE slicing and tiling.

| Workload | Untuned GEN | Tuned GEN | Tuned wall |
|---|---:|---:|---:|
| T2V-A14B | 201.45 s | 184.26 s | 325.4 s |
| I2V-A14B | 173.84 s | 157.36 s | 299.35 s |

Tensor checks passed 96/96 for both databases.

The validator rows in each CSV define where the files can be reused. Record and
tune a new database after changing the GPU architecture, PyTorch/ROCm libraries,
parallel layout, resolution, or frame count. Tune offline on one GPU; the
eight-GPU online search reached the thermal guard during testing.
